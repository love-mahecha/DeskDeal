 DeskDeal - Student Work Marketplace

A complete student work marketplace where students can post homework requests and earn money by helping others.

- Features

- User Authentication with Sessions
- Student Registration
- Buyer Flow: Post homework requests
- Worker Flow: Apply for work
- Accept/Reject System
- File Upload for Assignments
- Email Notifications Log
- Completed Deals Tracker
- Funny Prank Page
- Beautiful Wave Animation Background
- Mobile Responsive

 Installation

1. Clone: git clone https://github.com/love-mahecha/DeskDeal.git
2. Move to htdocs: mv DeskDeal /opt/lampp/htdocs/PHP/Student_work/
3. Start Apache: sudo /opt/lampp/lampp start
4. Open: http://localhost/PHP/Student_work/loginS.php
5. Login: student@123 / password123

Tech Stack

- PHP (Backend)
- HTML, CSS (Frontend)
- Session-based Storage
- XAMPP/LAMPP (Local Server)
